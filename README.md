# PWA- Cult and Clay 🌾✨(Repo Descp)

An interactive, high-intent Progressive Web App (PWA) prototype engineered for the **Cult & Clay** slow-fashion ecosystem. 

This repository acts as a live sandboxed pitch to demonstrate how introducing **digital tactility** and **event-deferred native app experiences** can dramatically increase digital engagement while lowering size-related e-commerce return blocks.

## 🛠️ Key Architectural Innovations Included
1. **Interactive Textile Provenance Map:** Bridges the digital divide by tracing Bengal Khadi, Raw Linen, and South Cotton back to specific generational artisan loops.
2. **"Slow Living" Conversational Fit Finder:** Swaps clinical sizing rows for an intuitive dialogue focused on volume mapping and fabric drape comfort.
3. **Capsule Wardrobe Drag Canvas:** Encourages zero-waste, multi-item intentional matching blocks before hitting checkout pipelines.
4. **Smart Deferred App Callouts:** Operates strictly as a clean, lightweight website initially, prompting a native home-screen installation card *only* after an action (like Add to Cart) is fired. Includes custom visual instructions tailored dynamically to Apple iOS Safari layouts.
